LINGUA 轻软实时翻译 · 桌面版 1.0
================================

界面采用薰衣草、樱粉和月光蓝配色，圆形角色图标，整体为轻柔的二次元风格。

启动
----
双击本文件夹中的 LINGUA.exe，或桌面上的“LINGUA 实时翻译”快捷方式。

每次启动会先显示免责声明。阅读后点“我已知晓并继续”；
如果不想以后再看到，勾选“不再显示此声明（永久关闭）”。
该偏好只保存在本机。

全局快捷键
----------
划屏：默认 Ctrl + Shift + F2
自动翻译：独立快捷键（默认候选 Ctrl + Alt + A；
         被系统占用时会自动选择可用组合）
两个快捷键都可以在设置中修改，互不影响。
划屏快捷键始终执行一次框选；自动翻译快捷键直接开始持续框选。

使用方式
--------
1. 打开主界面，选择输出语言。源语言默认是“自动检测”（支持 8 国语言）。
2. 按 Ctrl + Shift + F2，拖动鼠标框选屏幕上的文字。
3. 松开鼠标后自动 OCR、检测语言并翻译。
4. 主界面不会弹出；截图会冻结，译文按文本位置显示在对应原文的下方。
   不同位置的句子会分别显示；布局会自动避让原文、其他译文和提示条，互不重叠。
   句子较多时页面会自动延长，可用滚轮查看全部译文。
5. 按 Esc 退出。
6. 需要查看详细文本或修改语言时，右键托盘图标打开主界面。

自动翻译
--------
1. 点击顶部“自动翻译”标签。
2. 点击“框选自动翻译区域”，拖出需要持续翻译的区域。
3. 主界面隐藏，小译文框会显示在区域下方并持续更新。
4. 画面文字变化时立即翻译；画面不变时每 30 秒刷新一次。
5. 小译文框默认 80% 不透明度，可在设置中调整；按住小框空白处可拖动。
6. 点击浮层的关闭按钮或“停止自动”，即可停止监控。
7. 自动翻译使用独立全局快捷键，在任意页面都可以直接开始；不需要先切到自动翻译页。

托盘
----
点击窗口右上角 X 会隐藏到系统托盘，LINGUA 继续在后台运行，快捷键仍然有效。
右键托盘图标可以打开主界面、开始划屏或退出 LINGUA。

设置
----
点击右上角齿轮按钮：
- 划屏快捷键：点击“修改快捷键”，按下新的组合键（需包含 Ctrl / Alt / Win），
  设置立即生效；按 Esc 取消。快捷键会保存，重启后仍然有效。
- 自动翻译快捷键：同样点击“修改快捷键”单独设置，不影响划屏快捷键。
- 译文/提示不透明度：划屏滑杆同时控制原位译文标签、状态提示和
  Esc 关闭提示条；自动翻译滑杆控制自动翻译小浮层。
  可在 20%–100% 之间调整；数值越低越透明，保存后生效。
- 翻译引擎：可切换 MyMemory 或 OpenAI 兼容 API。
- API Key：勾选“在本机记住 API Key”后，密钥保存在本机，
  重启软件仍会自动填入。
- 快捷键、设置和密钥同时保存在 %APPDATA%\LINGUA\settings.json；
  如果未勾选“记住 API Key”，退出后需要重新输入。

API
---
默认可直接使用 MyMemory 免费接口。
可接入 DeepSeek、OpenAI、OpenRouter 或本地 Ollama 等 OpenAI 兼容 API。

首次启动
--------
应用未进行代码签名，Windows 可能提示“未知发布者”。
点击“更多信息 → 仍要运行”即可。

重要
----
请保持整个 LINGUA 文件夹完整，不要单独移动 LINGUA.exe。
建议把文件夹放在纯英文路径（例如 D:\LINGUA），不要放在中文路径下。

桌面版已内置 8 种 OCR 语言模型。首次使用“自动检测”时需要初始化多语言模型，可能稍慢；启动后会在后台预热。
屏幕截图只在本机识别，不会上传；识别出的文字会发送到所选的翻译 API。
